01 / GET RUNNING

Quickstart

Install dependencies from the repository root, then run the core and mobile checks.

pnpm install
pnpm typecheck
pnpm test
pnpm build

The mobile app imports the built @remi/core package. Rebuild core after changing it.

02 / HOW IT FITS

Architecture

Mobile app

Expo and React Native handle scanning, review, local SQLite documents, and sharing.

Core library

Pure TypeScript extracts field suggestions, checks totals, lays out receipts, and renders PDF and CSV exports.

Device storage

Drafts, source photos, and export versions stay in the app’s private document directory.

03 / ON DEVICE

Native builds

Remi’s scanner and image processor require a native build; Expo Go cannot load them. For local development on Android, use an Android SDK and a connected device or emulator:

cd apps/mobile
pnpm expo run:android
pnpm start

The public beta uses the preview EAS profile. It produces a standalone APK under com.remi.receipts.beta with a stable, Expo-managed signing key. Build it with:

cd apps/mobile
pnpm dlx eas-cli build --platform android --profile preview

See the README for iOS and development build details.

04 / WHAT MATTERS

Design rules

  • Money uses integer minor units; OCR never silently approves a value.
  • Export waits for confirmed receipt details and produces a reviewable cover sheet.
  • PDFs are views of editable local drafts, not the source of truth.
  • Receipt placement is stored in millimetres so the canvas and PDF agree.

Read the receipt scanning contracts for the native pipeline’s behaviour.
